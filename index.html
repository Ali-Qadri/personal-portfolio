Personal project / Restaurant operations

Restaurant ERP System

A restaurant management app that brings orders, menu, inventory, reservations, staff and expenses into one place. Each restaurant gets its own data and logins, with owner, manager and staff roles.

I designed and built it myself: the interface in plain HTML, CSS and JavaScript, Supabase for the database and sign-in, and an AI assistant that answers questions about your data and can create orders, reservations and menu items once you confirm.

Side project / AI web app

SiteSlap

A web app that audits any website in a real browser, scores it, and writes an honest, funny roast of what's wrong. Every issue comes with the evidence found on the page and a practical fix.

It checks speed, mobile layout, accessibility, broken links, SEO, navigation and content, then lets you pick a tone from friendly to savage. The scores come from measured checks, and the AI only writes the roast.

React / Chakra UI / Node.js / Express / Lighthouse / pa11y / Cheerio / AI roast writing
